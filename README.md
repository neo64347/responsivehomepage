# CloudOPS: Responsive Homepage

> Bootcamp practice project (2022). For educational purposes only.

A single responsive landing page for a fictional cloud-services company, **CloudOPS**. It has a hero section, a contact form, and a footer listing services (web design and hosting, cloud pricing calculator, VPC design).

**Live demo:** https://neo64347.github.io/responsivehomepage/

**Built with:** HTML · CSS · Bootstrap 5

**Run locally:** open `index.html` in a browser.
